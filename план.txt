#### 3. Аутентификация и JWT (6-7 часов) (все работает, все получилось)
**Что делаем:**
- Реализуем регистрацию и логин.
- Настраиваем JWT-токены в cookies.
- Добавляем middleware для проверки токена.

**Шаги:**
1. Создай схемы в `src/schemas/user.py` (см. предыдущий ответ).
2. Реализуй утилиты для JWT в `src/utils/auth.py`.
3. Добавь эндпоинты в `src/api/auth.py`:
   - Регистрация с хешированием пароля.
   - Логин с выдачей JWT в cookie.
4. Настрой middleware в `src/main.py`:
   ```python
   from fastapi import FastAPI, Request, HTTPException
   from src.api import router
   from src.utils.auth import decode_access_token

   app = FastAPI()

   @app.middleware("http")
   async def auth_middleware(request: Request, call_next):
       token = request.cookies.get("access_token")
       if token:
           try:
               decode_access_token(token)
           except:
               raise HTTPException(status_code=401, detail="Invalid token")
       response = await call_next(request)
       return response

   app.include_router(router)
   ```

**Время:** 6-7 часов (включая изучение JWT и middleware).

**Шаги:**
1. Создай схемы в `src/schemas/article.py`:
   ```python
   from pydantic import BaseModel

   class ArticleCreate(BaseModel):
       title: str
       content: str
       category_id: int

       id: int
       title: str
       content: str

   ```
2. Реализуй эндпоинты в `src/api/articles.py`:
   - GET `/articles` с параметрами `search`, `category_id`, `page_number`, `page_size`.
   - POST `/articles` (загрузка изображения в MinIO).
   - PATCH `/articles/{id}`.
   - DELETE `/articles/{id}` (фейковое удаление).
3. Настрой MinIO в `src/utils/s3.py`:
   ```python
   from minio import Minio
   from src.core.config import settings

   minio_client = Minio(
       settings.MINIO_URL,
       access_key=settings.MINIO_ACCESS_KEY,
       secret_key=settings.MINIO_SECRET_KEY,
       secure=False
   )

   def upload_image(file):
       minio_client.put_object("images", file.filename, file.file, length=-1, part_size=10*1024*1024)
       return f"http://{settings.MINIO_URL}/images/{file.filename}"
   ```
4. Настрой полнотекстовый поиск:
   - Добавь индекс в модель `Article`:
     ```python
     from sqlalchemy import text
     __table_args__ = (Index('ix_articles_title_content', text("to_tsvector('russian', title || ' ' || content)"), postgresql_using='gin'),)
     ```
   - Используй в запросе:
     ```python
     query = query.filter(text("to_tsvector('russian', title || ' ' || content) @@ to_tsquery('russian', :search)")).params(search=search)
     ```

**Время:** 8-10 часов (включая работу с S3 и полнотекстовым поиском).
